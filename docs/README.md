# Swagger / OpenAPI

Спецификация API: [openapi.json](openapi.json).

После `go run ./cmd/api` документация доступна по адресу `http://localhost:8080/swagger/`, а JSON OpenAPI — по адресу `http://localhost:8080/swagger/openapi.json`.

Интерфейс Swagger UI загружается с CDN; для отображения интерфейса нужен доступ браузера в интернет. Сама спецификация доступна локально без интернета.
